# piano.

### A tiny, self-contained browser piano made for the SHRINK challenge.

## Play

### Open src/index.html in a browser. Click or tap the keys, or use:


## White keys: A S D F G H J K


# Black keys: W E T Y U


# Arrow keys or the octave button: change octave

## The first interaction unlocks the Web Audio synth. No internet, packages, images, or external libraries are needed at runtime.

`Build a data URI`


`npm install
node build.mjs`



## The one-line app is written to dist/uri.txt and the minified page to dist/index.html.
